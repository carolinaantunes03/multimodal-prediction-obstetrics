# Tabular-Only Experiments for Predicting Mode of Delivery After IOL

This folder presents the code used for experiments with only tabular data. 

## Run Tabular-Only Experiments 

Use `tabular_classic_models.py` to train and test some classic ML models to predict mode of delivery. If you want to train and test FT-Transformer you need to run `train_FTTransformer.py`This folder is prepared to receive the 3 cross validation folders from the retrospective dataset.
